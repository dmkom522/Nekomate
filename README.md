# Nekomate

网课内容太难，节奏太快，想要问大模型老师说的话是什么意思，只好先截图，再倒回去转述原话，程序却因为没有老师说话的上下文回答不到点子上？Nekomate来帮你！从此不用截图，不用绞尽脑汁思考如何给模型网课的上下文信息，你的小猫同桌会帮你解决一切！

Nekomate是你的小猫同桌，可以陪你一起听网课，当你遇到不懂的问题，直接问它：“ppt上的红色方块是什么意思？”，然后等待它告诉你准确而直接的答案！就像真的一直在陪你上课，它知道这节课在干什么，而不是“我现在正在上cs231n，刚刚老师在讲vit，结合画面告诉我老师‘.....这句话中的xxx是什么意思，前面他说.....’”

**看视频时，点一下桌宠，问清没懂的那一步。**

打开应用，桌面上会出现一只小猫。点击它弹出小聊天气泡，直接输入问题，回答留在气泡里。首次右键小猫，通过菜单配置 API 并选择课程窗口，然后收起面板继续看课。后台画面、提问时新增的音频转写和问题都进入当前学习的同一段对话。有问题时再点桌宠，当前截图直接和问题一起发送。

拖动桌宠可换位置，右键小猫打开菜单。关闭问答面板会收回桌宠，继续已开启的采集；菜单中的「暂停学习」和「退出 Nekomate」可随时停止。

独立桌面应用 · 自带 API · 中英文界面 · 本地记录 · MIT 开源

## 下载使用

在 [Releases](https://github.com/dmkom522/Deskmate/releases) 下载 `Nekomate-版本-win-x64.exe` 安装程序。普通使用者**不需要 Node.js、Python 或开发环境**。

首版以 **Windows 10/11 x64** 为交付目标。macOS / Linux 保留源码构建入口，目前不承诺平台适配和系统声音可用。

1. 安装并打开 Nekomate，点击桌面上的小猫展开问答。
2. 从小猫右键菜单打开 **API 设置**，先选服务商，再选 API 或本机 CLI。填写 API 地址与密钥，或检测本机 CLI，然后从自动读取的列表中选择模型。CLI 需提前安装并登录。
3. 点击 **选择学习窗口**，选择浏览器、播放器或其他课程窗口。
4. 看课时后台自动读取画面。遇到问题点桌宠，在气泡里输入“这一步为什么成立？”，按 Enter 发送，Shift + Enter 换行。

Nekomate 不附带模型额度。API 费用由你选择的服务商收取。安装包尚未使用商业代码签名证书；Windows 可能显示未知发布者，请核对下载来源与 Release 提供的校验值。

## 它能做什么

- **选择窗口或屏幕**：带缩略图的应用内选择器，不需要抓取网站内部接口。
- **提前读图**：后台逐张读取自动截图，记录公式、板书与推导步骤。提问时另截取当前画面，以图片和问题一起发到同一段学习对话。
- **快速答疑**：支持的模型旁显示闪电开关，默认关闭，只对答疑申请快速处理；可能增加费用或额度消耗。
- **讲解转写**：Windows 系统声音在本机内存滚动保留最近两分钟，提问时只转写其中尚未处理的部分；默认使用内置 Qwen，也可主动选择支持音频的当前模型进行云端转写。
- **连续追问**：一段学习持续使用同一上下文。CLI 恢复对应的原生会话；API 保留并按协议发送完整的对话消息。
- **数学与代码呈现**：本地 Markdown、KaTeX 公式渲染，不依赖在线 CDN。
- **历史记录**：在“一起听课吧！”下方打开本机历史并恢复其模型会话；开始新的学习会保留旧对话。没有模型绑定的旧版记录仅供查看。
- **自选服务**：视觉问答支持自选 API 或 CLI，本地转写无需密钥；可选云端转写复用当前模型配置。
- **中英文界面**：在设置顶部选择“界面语言 / Language”，即时切换并记住选择，不需要先配置模型。

## 先了解这些边界

Nekomate 目前是 **0.1 早期版本**，还不是完整课程知识库。

- 画面是抽样，不是完整录像。自动截图先在本机保存待处理文件，再按顺序读图；笔记成功写入本机记录后才删除相应待图文件。已成功保存的待图可在重启后继续处理，快速动画或推导仍可能遗漏；提交后的图片也可能随 CLI 原生历史或 API 对话消息保存在磁盘。
- 背景读取一次处理一张图；两次自动截图至少间隔 30 秒，画面无明显变化时不重复发送（并不等于识别到了播放器暂停）。回答或上一张读图尚未结束时，后续抽样截图先排队，空闲后按时间顺序送入当前对话。
- 只有开始新的学习才建立另一段模型对话。CLI 的后台图片、课程背景、转写和问题进入同一原生会话，后续只提交新增内容；重启或切换历史按绑定的 ID 恢复，恢复失败会报错，不另建会话。API 没有因此变成服务器持久线程：应用维护完整消息序列，按 Chat Completions / Messages 协议随请求发送。原生 CLI 自行管理上下文；应用不承诺手动压缩、无限上下文或不触及服务商上限。
- 正在采集时，每次提问立即截取所选课程窗口，将这张新图直接与问题、新增转写一起发送，不先生成笔记；静止画面也会截取。已有内容由同一会话保留，不再挑选若干旧笔记拼成新的 CLI 会话。笔记本身可能误读或遗漏，不能保证答复准确，也不能保证服务商响应速度。
- 显示的是**听课会话时间**，不是 B站等播放器的课程时间；暂不支持跳回原视频。
- 系统声音可能包含其他应用的声音，**不是仅所选窗口的声音**。Windows 默认勾选系统声音，可手动关闭；原始音频只在内存缓存，默认提问时在本机转写，不上传原始音频、不自动采集麦克风。仅处理最近 120 秒内尚未转写的音频，已处理片段不反复转写；更早且未处理的声音被覆盖后无法补录。
- 最小化、受保护的视频或系统权限限制可能导致画面停止更新或黑屏。先看预览再开始。
- 未接收音频转写时，模型只有画面和对话。转写失败会提示，本次提问仍结合当前截图和已有记录继续回答；用户主动取消时不会降级后继续发送。模型答复可能有误，应对照来源检查。
- 启动时恢复上次打开的会话，其他会话保留在历史列表。突然退出时尚未保存的变化可能丢失；记录仅保存在这台电脑。

## 模型连接

先选择 OpenAI、DeepSeek、Claude 或其他服务，再展开连接配置。

| 服务 | API 方式 | 本机 CLI 默认选项 |
| --- | --- | --- |
| OpenAI | Chat Completions | Codex CLI |
| DeepSeek | 直接连接 DeepSeek API（Chat Completions） | — |
| Claude | 原生 Messages | Claude Code |
| 其他服务 / 本地 API | 可选 OpenAI 或 Claude 格式 | 可选上述 CLI |

DeepSeek 直接填写自己的 API 地址、密钥并选择模型，不经过 Claude Code。其他服务的 CLI 方式使用程序自身的登录与服务配置，服务商选项不会替你改变 CLI 的后端。路径留空先从 PATH 查找，再检测常见安装目录，也可选择本机路径。CLI 本身需要单独安装，使用 npm 安装的 CLI 还需要 Node.js；本机 CLI 不等于离线模型或免费额度。详细步骤见 [连接指南](docs/CONNECTIONS.md)。

API 与 CLI 模型均使用下拉选择。聊天输入框底部也能切换当前连接的模型，并保存选择。列表依据服务 / CLI 能力元数据及已核对的模型规则筛选。语音默认使用内置 Qwen3-ASR 0.6B（优先显卡，不可用时使用同一模型的 CPU 模式）；只有当前图片模型确认支持转写时，才显示默认不勾选的“使用所选模型转写音频”。筛选不代表账户一定有调用权限，获取失败时可以刷新。

### API 格式

| 功能 | 接口 | 必须支持 |
| --- | --- | --- |
| 视觉问答 | `POST {baseUrl}/chat/completions` | Chat Completions 多模态消息、base64 `image_url`、文字回复 |
| Claude 视觉问答 | `POST {baseUrl}/messages` | Anthropic Messages、base64 图片块、文字回复 |
| 可选云端转写 | `POST {baseUrl}/audio/transcriptions` 或 `/chat/completions` | 用户主动勾选，且所选图片模型支持 WAV multipart 转写或 `input_audio`；不会改用其他模型 |

基础地址不要再加 `/chat/completions` 或 `/messages`。仅支持文字的模型无法完成画面答疑。默认本地转写无需额外密钥，也可配合 CLI 和 Claude Messages 使用。可选云端转写共用当前模型的地址与密钥，切换模型或连接后恢复默认本地。API 请求使用 Electron 系统会话的网络和代理配置。当前验证覆盖本机 HTTP、HTTPS 代理和 CLI 协议夹具，不代表各家真实账户或模型已完成验收。

## 隐私

应用没有 Nekomate 云端、用户账号、遥测或广告。密钥由 Electron `safeStorage` 调用操作系统的加密存储保护，渲染界面只能读取“是否已保存”。系统密钥服务不可用时仅保存在内存。

配置连接并开始听课后，自动截图会排队提交给你选择的模型，用于后台读取并产生服务用量；提问发送当前新截图、问题和尚未提交的新转写。CLI 将这些内容追加到当前原生会话；API 请求按协议包含当前对话的完整消息，已有图片也可能再次随历史消息传输。暂停学习会停止新截图请求并取消正在进行的读取（已到达服务商的请求可能仍计费）。音频最多保留最近两分钟，默认提问时在本机增量转写；只有主动启用所选模型转写才上传相应原始录音，暂停不会触发上传。切换窗口、新的学习或退出会清除原音频缓存。窗口选择器缩略图不发给模型。API 服务商有各自的数据处理政策。

本机界面记录保存笔记、转写文字、对话与草稿；另有模型会话绑定和接收记录。待处理自动截图会以实际图片及窗口来源保存在 `userData/pending-frames/<sessionId>/`，并非只有排队数量或时间标签；笔记保存成功后清理该队列文件。API 的完整对话消息可能包含截图，CLI 自己的原生历史也可能持久化图片。不要将这些目录当作不含截图的纯文字记录。原始录音不写入学习记录，API Key 不写入对话消息。

CLI 模式将资料交给所选程序，每段学习使用固定工作目录 `userData/learning-sessions/<id>/work`，不会每次推理另建并删除临时目录。绑定记录用于恢复同一原生会话；CLI 自己的账户、缓存和历史仍由各家程序管理，可能保存在其他目录。删除界面的历史记录不等于清除了 CLI 的原生历史；具体数据处理规则以对应 CLI 与服务商为准。

每个新对话开始学习后，最多收集 3 张不同画面，集中识别课程并补充背景；首张画面后 30 秒仍不足 3 张时使用已有样本。只在这一阶段开放 Codex / Claude Code 的内置网页工具，以及 DeepSeek API 的官方 Search / Fetch（同一地址和密钥，按服务商规则计费）。课程检索同样进入当前学习会话；已提交的抽样图不作为新的图片重复追加。后续读图和答疑关闭搜索工具，复用本对话的背景；恢复历史不会重新检索，开始新的学习使用独立背景。初期抽样复用本次采集的截图；自动截图按待处理文件规则保存在本机，提交后的样本也可能进入模型历史。检索失败或取消不会在之后每张画面反复重试。其他普通 API 只从截图提取背景，不会声称联网查证。网页信息不代表老师实际讲过，线上可用性仍取决于所连服务和账户。

## 从源码启动

开发者需要 Node.js 22+，建议 Node.js 24。

```bash
git clone https://github.com/dmkom522/Deskmate.git
cd Deskmate
npm ci
npm start
```

```bash
npm test             # 核心逻辑和真实本地 HTTP 请求测试
npm run check        # JavaScript 语法检查
npm run test:desktop # 桌面界面与模拟采集输入集成测试
npm run dist:win     # 生成 Windows x64 安装程序
```

开发测试、真实窗口采集和真实模型问答是不同层级的验证，详见 [验证说明](docs/VALIDATION.md)。
