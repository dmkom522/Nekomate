Nekomate：桌面上的小猫同桌，陪你理解课程中的概念、公式和推导。

### 当前源码版本

- 桌宠、聊天气泡和主页面；右键菜单控制学习，关闭小猫退出整个应用，重复启动保持单实例。
- 自动截图最短间隔 30 秒，画面不变时跳过。回答期间继续采样，待处理图按会话保存到本地，回答结束及重启后继续补记，笔记保存后清理对应待图缓存。
- 提问时直接发送当前截图。暂停学习停止新的画面和声音采集，已有待图仍可继续处理。
- Codex / Claude Code 一段学习绑定一个持久原生会话；API 保留完整消息链。恢复失败不自动创建替代会话。
- 语音默认使用 Qwen3-ASR 0.6B 在本机转写，显卡优先、同模型 CPU 回退。仅在提问时处理最近两分钟缓存中尚未转写的声音；转写失败提示后仍可结合画面回答。
- 当前模型确认支持音频时，可主动选择云端转写，默认关闭。DeepSeek API 直连；保留 Codex 与 Claude Code CLI。
- 新学习初期集中识别课程背景，支持的连接可搜索公开资料。日常读图和每次提问不重复搜索。
- 中英文界面、模型快速模式、Markdown 与 LaTeX、本机历史搜索/重命名/删除，以及独立草稿。

### 安装包分发

当前提交以源码为交付内容。HaujetZhao/Qwen3-ASR-GGUF 推理实现作为固定版本的构建依赖获取，不将其完整实现纳入本项目源码仓库。尚未从该固定版本找到明确的仓库级再分发许可证；Qwen 模型的 Apache-2.0 许可不等同于该实现的许可，详见 `assets/licenses/Qwen-GGUF-NOTICE.txt`。

自动构建和发布安装包默认关闭。确认相关组件的二进制分发授权后，可在仓库变量中设置 `ALLOW_QWEN_BINARY_REDISTRIBUTION=true`，再使用版本标签发行。普通源码 CI 与测试不因此关闭。

### 使用边界

这是 0.1 早期版本，Windows 10/11 x64 为当前目标。画面采样不是完整录像，音频是 Windows 系统混音，无法隔离单个应用。模型上下文和服务额度仍有限制，原始音频只在内存保留最近两分钟。截图与转写可能识别错误；本机受控服务测试不代表各家真实账户或课程理解质量。

Nekomate 不附带模型额度，API 和 CLI 用量由对应服务商收取。本地构建的安装程序尚未使用商业签名证书。
