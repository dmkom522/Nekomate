Nekomate v0.1.1 是面向 **Windows 10/11 x64** 的预览更新。桌面上的小猫陪你看课，结合课程画面和讲解，解释没弄懂的概念、公式与推导。

## 本次更新

- 调整公式输出提示词：行内公式统一使用 `\(...\)`，独立公式统一使用 `\[...\]`，独立公式前后留空行。
- 禁止模型使用美元符号包围公式，或把公式放入反引号和代码块。

## 下载与安装

1. 下载本次 Release 的 `Nekomate-0.1.1-win-x64.exe`，可用同页 `SHA256SUMS.txt` 核对文件摘要。
2. 运行安装程序，选择安装位置。应用自带本地语音转写模型和运行时，**无需另行安装 Node.js 或 Python**。
3. 右键小猫打开 **API 设置**，连接支持图片输入的 API 或已安装并登录的 CLI，选择模型并保存；再选择课程窗口开始学习。

安装程序尚未使用商业代码签名证书，Windows 可能显示未知发布者提示；请核对下载来源和摘要。Nekomate 不附带模型额度，API / CLI 的账户权限、费用与限流由对应服务商决定。

## 这个版本包含什么

- **桌面小猫与聊天气泡**：右键打开主页面和设置；可拖到屏幕边缘收起为耳朵，听课时用静态书本表示状态。重复启动保持单实例，关闭小猫退出整个应用。
- **当前画面直接答疑**：提问时立即冻结截图，和问题一起交给模型；Markdown、LaTeX 公式和代码在本地渲染。
- **后台连续记录**：自动截图最短间隔 30 秒，画面不变时跳过；回答期间继续采样并排队。待处理原图按学习会话保存到本机，重启后可继续补记，笔记保存成功后清理对应待图。
- **同一段学习持续追问**：Codex / Claude Code 绑定并恢复同一原生会话；普通 API 保留完整消息链。开始新的学习创建另一段对话，恢复失败不自动另建会话。
- **默认本地语音转写**：Qwen3-ASR 0.6B 支持中英文，显卡优先、同模型 CPU 回退；只在提问时处理最近两分钟缓存中尚未转写的声音。转写失败会提示，并继续结合画面与已有资料回答。
- **自选连接**：DeepSeek API 直连，支持 Codex 和 Claude Code CLI。当前模型确认支持音频时可主动选择云端转写，默认关闭；新学习初期可通过支持的连接集中查询课程背景。
- **日常操作**：中英文界面、支持模型的快速模式、本机历史搜索／重命名／删除及每段对话的独立草稿。暂停学习停止新的屏幕和声音采集，已保存的待图仍可继续处理。

## 使用边界

这是早期预览版。画面抽样不是完整录像，可能漏掉快速变化；Windows 系统混音可能包含其他应用，不能保证只采集课程声音。原始声音只在内存滚动保留最近两分钟，未转写的更早内容会被覆盖。

截图、问题和转写文字发送到你选择的模型服务；待图及模型会话可能在本机保存截图，CLI 也可能保留自己的历史。模型上下文、额度和识别质量仍有限制，测试通过不代表所有真实账户或课程都已验收。没有绑定原生模型会话的旧版历史仍可查看，需要开始新的学习才能继续使用模型。

当前发布目标为 Windows x64；macOS / Linux 的本地转写和采集适配尚未完成验收。
