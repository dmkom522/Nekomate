Deskmate 的首个公开桌面版本：选择课程窗口，带着近期画面随时向你配置的 AI 提问。

### 下载

Windows 10/11 x64 用户下载下方 `.exe` 安装程序。无需开发环境。安装后在 API 设置填写自己的视觉模型服务地址、模型名与密钥。

### 功能

- 窗口选择、预览、关键画面回看和连续问答。
- 可选系统声音转写，支持独立的转写服务。
- 数学公式、代码、来源标记和本机学习记录。

### 使用边界

这是 0.1 早期版本。画面是有限缓存内的抽样，不是完整录像；单次问答最多 8 张图片。时间是陪学时间，不是原视频进度。Windows 声音是系统混音，不隔离单个应用。真实课程答疑效果取决于你配置的视觉模型，模拟 API 测试不代表模型理解准确。

本安装程序未使用商业签名证书，Windows 可能显示未知发布者。请核对来源和 SHA256SUMS.txt。API 费用由服务商收取，Deskmate 不附带额度。
