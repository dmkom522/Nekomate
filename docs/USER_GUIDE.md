# 使用指南

## 第一次打开

从仓库 Releases 下载安装包。安装向导允许选择路径，完成后打开 Deskmate。

点击左下角 **API 设置**：

- **API 基础地址**：服务商提供的兼容接口根地址，例如 `https://api.example.com/v1`。
- **模型名称**：填写模型 ID，不是聊天网页的名称。需要支持图片输入。
- **API Key**：自己的密钥。界面留空会保留已保存的密钥；勾选清除可以删除。

保存配置只证明设置已接受，不会调用模型或验证其视觉能力。实际提问才会产生问答请求。

## 开始陪学

1. 打开课程，先让板书或幻灯片清晰可见。
2. 在 Deskmate 点击 **选择学习窗口**。选择具体窗口能避免把其他窗口混入画面。
3. 检查实时预览；如果黑屏，请保持课程窗口可见，检查系统录屏权限。受保护的视频可能无法采集。
4. 正常看课，遇到不懂的地方可在播放器中暂停，然后回到 Deskmate 提问。Deskmate 不控制原播放器。
5. 需要强调某一刻时点 **保留这一刻**。点击下方历史截图可放大，并选择 **带上这张画面提问**。

“最近 1 / 3 / 10 分钟”以所选画面为结束位置；没有选择时以当前最近画面为结束位置。最多均匀选 8 张，不能保证完整覆盖每一步。

## 声音与转写

声音和转写是两个独立开关：

1. 在 API 设置填写转写服务地址、模型与密钥，打开 **自动转写**。
2. 在窗口选择器勾选 **同时采集系统声音**。

Windows 系统声音可能包括音乐、通知和其他程序。这里不采集麦克风，也不保证隔离单个应用。

每段音频约 30 秒，最后不足一段的内容在提问或停止时完成。提问可能需要等待正在转写的片段；单次 API 请求超时为 90 秒。连续积压或错误会暂停上传，可在 API 设置中保存配置后恢复。窗口采集仍可继续。

## 查看回答与来源

模型应引用 `[F1]` 等画面或 `[T1]` 等讲解来源。每条回答下方的来源按钮可打开对应画面或讲解。编号只属于当前这条回答；不同回答的 F1 可能不同。

超出缓存范围的旧画面无法再打开。历史对话保留文字，但这不意味着所有旧图片仍会发送给模型。

## 保存和恢复

最近一次学习每约 10 秒自动保存在本机，下一次打开会恢复。点击 **导出本次记录**可保存 JSON，包含当前缓存画面、讲解、对话和采样诊断，不包含密钥。

开始新学习会清空当前会话。打开导出的记录前，先导出并清空当前会话，避免覆盖。

## 常见问题

| 现象 | 检查方法 |
| --- | --- |
| API 401 | 检查密钥是否有效、是否有该模型权限 |
| API 404 | 检查基础地址和模型 ID；不要重复填写接口路径 |
| API 400 | 确认模型支持 base64 图片和 Chat Completions 多模态格式 |
| API 429 | 查看服务商额度或限流设置，减少提问频率 |
| 无法连接 API | 检查网络。远程接口必须是 HTTPS，本地服务可用 HTTP |
| 没有讲解记录 | 检查声音轨道、自动转写开关、转写模型与地址 |
| 公式看不清 | 放大课程窗口或画面，采集更清晰的一帧再问 |
| 模型说错了 | 对照来源；问“你依据哪张图？缺少了什么前提？” |

本版不内置代理设置。需要代理的 API 可通过提供兼容 HTTPS 接口的网关，或使用本机兼容服务。不要把密钥放进 URL。
