# 使用指南

## 第一次打开

从仓库 Releases 下载安装包。安装向导允许选择路径，完成后打开 Nekomate。

启动后先出现桌宠，不会自动采集。点击桌宠弹出聊天气泡，再从小猫右键菜单打开 **API 设置**，进入独立设置页面：

设置顶部的 **界面语言 / Language** 可选择 **中文（简体）** 或 **English**，切换后立即保存，重启沿用。主页面、气泡、菜单、桌宠标签和提示会同步切换；未发送问题、未保存的连接字段及已有课程内容保留原样，不需要重新开始学习。

先选服务商。DeepSeek 直接展开 API 配置；其他服务可选 **API** 或 **本机 CLI**。API 方式填写：

- **API 基础地址**：对应服务的根地址，选择服务商后会预填，可以修改。
- **模型**：地址和密钥填好后自动获取列表，从下拉框中选择支持图片输入的模型；可点击“刷新模型”重试。
- **API Key**：自己的密钥。界面留空会保留已保存的密钥；勾选清除可以删除。

切换服务商或地址后不会沿用旧服务的密钥。CLI 方式填写或选择对应程序的本机路径（留空自动查找），模型自动读取后下拉选择并保存；需要提前安装并完成该 CLI 的登录或接口配置。检测安装只检查程序版本与命令能力，不验证账户额度或图片理解。详见 [连接指南](CONNECTIONS.md)。

保存配置只证明设置已接受，不验证模型理解能力。API 和 CLI 都必须先从成功读取的模型列表中选择支持图片输入的模型并保存，才能开始学习；未完成时会先打开 **API 设置**，不会开始共享屏幕或声音。配置完成后选择课程窗口，自动截图会发给视觉模型读取并产生费用。

## 开始听课

1. 打开课程，先让板书或幻灯片清晰可见。
2. 从小猫右键菜单打开 **主页面**，点击 **选择学习窗口**。选择具体窗口能避免把其他窗口混入画面；重新选择窗口默认继续当前课程。
3. 检查实时预览；如果黑屏，请保持课程窗口可见，检查系统录屏权限。受保护的视频可能无法采集。
4. 点击 **收起** 或关闭面板，已开启的采集会继续。正常看课，遇到不懂的地方可在播放器中暂停，点击桌宠展开问答。Nekomate 不控制原播放器。
5. 在小气泡里输入问题，Enter 发送，Shift + Enter 换行。小猫思考后，回答显示在气泡里；较长内容可以滚动。菜单中的 **主页面** 可打开含实时预览的完整页面。

输入框底部显示当前模型，可以直接下拉切换；气泡和完整面板共用这个选择。切换会保存，之后的截图读取与提问使用新模型。正在回答时暂时不能切换；旁边的刷新按钮可以重新读取列表。

后台逐张读取新截图并保存理解结果，后台消息进入当前学习的同一段模型对话。自动截图至少间隔 30 秒，静止画面不重复发送；画面变化后恢复读取。这是本地画面变化检测，不能保证识别播放器暂停，正常读取过程不展示进度或日志。回答或后台读图尚未结束时，按原规则截取的新画面先保存为本机待处理文件，空闲后按时间顺序送入同一会话；笔记成功写入本机记录后才删除相应待图文件。提交后的图片还可能随模型历史保存在磁盘。接口错误会暂停读取并提示，可重试当前任务；若原生会话无法恢复，不会新建另一个会话来掩盖错误。点击 **暂停学习** 会停止新增屏幕和声音采集；已经保存的待处理截图仍会继续补记，已有记录保留，已发送的问题可继续回答。继续采集新画面时重新选择学习窗口，默认沿用当前课程。

要开始另一门课，可从右键菜单或主页面点击 **开始新的学习**，创建独立对话。只有这一步会为学习建立新的模型会话；重新选择课程窗口、暂停后继续或追加问题都沿用当前会话。右键新建不会弹出主窗口，也不会把聊天气泡切成主页面。旧对话、学习记录和未发送草稿保留在历史记录中。

正在采集时，每次发送问题都会立即截取所选课程窗口，不受后台 30 秒间隔或静止画面去重限制。新截图直接和问题、新增转写一起交给当前模型会话回答，不先生成笔记；先前未完成的后台读图会让出处理顺序。未能截取当前画面或回答请求失败会明确报错，保留问题供重试，不用旧笔记代替当前截图另行回答。图片不作为普通聊天条目展示，但可能进入 CLI 原生历史或 API 的完整消息记录。

提问时还会按转写设置处理最近两分钟缓存中尚未处理的声音，新增转写和新截图一起进入答疑请求。取消问题会取消答疑及仍在进行的转写；接口或 CLI 超时会报错，已送达服务的请求可能仍计费。没有正在共享的课程窗口时，追问沿用该会话已有上下文，不会擅自截取整个桌面。回答质量仍取决于识别准确性和记录是否覆盖关键步骤。

## 桌宠操作

- 点击桌宠：展开 / 收起小聊天气泡。打开后可直接输入问题。
- 聊天、主页面和设置窗口使用普通窗口层级，点击其他应用可将它们盖住；只有小猫保持悬浮。
- 拖动桌宠：调整位置，打开的气泡随它移动。默认出现在主屏幕右下角。可以继续将猫身拖出屏幕，越过边缘约三成后松手，小猫沿该方向收起，只露出两只耳朵；仍在屏幕内时松手不会触发收起。鼠标靠近耳朵时会探出一点额头，移开后缩回。点击耳朵平滑叫回整只小猫，不会自动打开聊天；也可直接拖着耳朵离开边缘。收起不会停止已开启的采集。
- 右键小猫（收起时右键耳朵）：打开主页面、开始新的学习、选择学习窗口、打开 API 设置、暂停学习或退出应用。提问直接点击小猫打开聊天气泡。
- 小猫不再显示悬浮文字提示框。思考时尾巴轻微闪动，回答以文字显示在气泡中。
- 正在听课时，小猫保留原来的表情，身前放着一本展开的书，像在看书。书本、身体和尾巴保持静止，不播放听课动画；暂停学习后收起书本。
- 关闭问答面板并不退出应用。要结束听课并关闭桌宠，请在桌宠菜单中选择 **退出 Nekomate**。
- 通过系统关闭操作关闭小猫窗口时，也会退出整个应用，不留下隐藏后台实例。
- 小猫已经运行时，再点桌面快捷方式不会创建新的小猫，也不会弹出窗口、抢焦点或改变当前位置。退出应用后可以再次打开。

## 课程背景查询

每次开始新的学习后，Nekomate 会从初期画面中选取最多 3 张不同截图，集中判断课程主题并补充背景。Codex / Claude Code 使用内置网页工具；DeepSeek 直连使用现有密钥调用官方搜索和网页读取，不需要再配置搜索服务，可能单独计费。后续读图、提问与恢复历史对话都复用保存的背景，不重复搜索。若画面一直不变，30 秒后使用已有样本；不能确认具体视频时，不猜测课程名或讲者。检索失败不妨碍继续提问。其他 API 目前只从抽样画面归纳背景。

## 声音与转写

Windows 窗口选择器默认勾选 **同时采集系统声音**。音频在本机内存里滚动保留最近两分钟，旧声音自动覆盖；看课期间不会调用转写 API。没有满两分钟时使用已经录到的内容。

默认使用随应用内置的 Qwen3-ASR 0.6B 在本机转写，优先使用显卡，不可用时使用同一模型的 CPU 模式，支持中文和英语等语言，无需语音 API 或另行安装 Python、模型。提问时仅处理最近 120 秒内尚未转写的录音，已经处理过的重叠部分不再反复识别；新增转写进入当前学习会话。若两次提问相隔较久，超过缓存范围且未处理的旧声音已被覆盖，无法事后补转写。CLI 和 Claude Messages 连接也可使用本地转写。

当当前所选图片模型的目录确认支持音频输入或转写接口时，API 设置会显示 **使用所选模型转写音频**，默认不勾选。勾选并保存后，提问时才把录音交给该模型，沿用同一地址和密钥，不自动改用服务里的其他转写模型。切换模型、地址、密钥或连接方式会恢复本地默认，需要重新选择。取消勾选即可恢复本地转写。

暂停学习会停止声音共享，保留已经生成的转写文字。切换窗口、开始新的学习或退出应用会清除音频缓存，原始音频不会写入本机学习记录。转写文字随会话保留，确认已提交的片段不会再次作为新消息追加；恢复历史沿用相同上下文，不重新上传历史音频。

Windows 系统声音可能包括音乐、通知和其他程序。这里不采集麦克风，也不保证隔离单个应用。不需要声音时可取消勾选。

提问会多等待一次转写，转写请求最多等待 90 秒。可用 **取消** 中止当前等待；本地转写会结束独立工作进程，空闲一分钟后也会释放模型内存。转写失败时会显示提示，本次问题仍结合提问时的新截图和已有记录继续回答，不因缺少本次转写而整条失败。失败的音频范围不会被当作已成功处理，下一次提问仍可转写缓存中保留的部分；已经超出两分钟缓存的声音无法恢复。主动取消或切换会话时不会继续发送旧问题。云端服务已经接收的请求可能仍计费。转写可能误认专名和术语，应结合画面核对。

## 查看回答与学习记录

回答留在聊天气泡或主页面中，后台读图和转写属于同一学习的上下文，不需要模型在回答后添加内部笔记来源标签。旧版回答如保留来源按钮，可查看当时保存的文字资料。

模型会话记录可能保存已提交图片，但这不代表界面提供完整课程录像或逐帧回放，也不保证旧图始终处在模型当前可用的上下文中。

## 保存和恢复

学习内容变化后自动保存在本机，下一次打开会恢复上次选中的对话。界面记录包含笔记、转写文字、对话、输入草稿和采样诊断；模型会话还保存绑定和接收状态。自动采样但尚未完成笔记的原图与窗口来源会另外保存在 `userData/pending-frames/<sessionId>/`。恢复对应历史后会继续处理已保存的待图，无需重新共享窗口，也不会因此自动开启新截图或录音。笔记成功保存后清理相应队列文件；文件损坏或磁盘保存失败会提示并保留可用记录，不静默跳过。CLI 原生历史与 API 的完整消息序列可能包含课程截图。原始音频不写入学习记录，API Key 不写入对话消息。

CLI 模式按绑定的原生 ID 恢复同一段学习，后台图片、转写和问题只提交新增内容。每段学习使用固定工作目录 `userData/learning-sessions/<id>/work`；恢复失败会显示错误，不另建模型会话。账户或连接变化时，需要切回原连接，或明确开始新的学习。

API 模式由应用保存完整对话消息，每次按 Chat Completions / Messages 协议发送已有历史及本次新增内容；这不是 API 服务端持久线程，也不再从历史中挑选若干笔记拼接。旧图片可能随历史消息再次传输。原生 CLI 自行管理其上下文，应用不提供手动压缩承诺；长对话仍可能触及模型上下文或服务上限。

画面笔记、转写和对话不再因为超过二十分钟或消息数达到上限而自动删除。较长对话默认显示最近 60 条消息，可以点击“显示更早的消息”查看完整记录。已有版本曾自动移除、且没有保存的内容无法凭空恢复。

回答失败时，原问题和错误仍留在对话中。输入框中已写的新草稿保持不变；只有输入框仍为空、发送后没有再编辑时，才恢复失败的问题方便重试。

“一起听课吧！”下方的“历史记录”按最近更新时间列出对话，以第一条问题或课程窗口名称作为标题。点击即可打开并继续提问，无需选择文件。输入搜索词可查找标题和聊天内容，每条记录旁的“···”可重命名或删除，删除前会再次确认；每段对话分别保留未发送草稿。点击 **开始新的学习** 会创建独立对话并保留旧对话和草稿；切换历史对话会暂停当前学习并清除原始音频缓存，需要看新画面时重新选择窗口。

旧版自动保存的最近一次会话会迁入历史列表。没有模型会话绑定的旧记录只可查看，不能靠重新选择窗口继续提问；请点击 **开始新的学习** 建立新的上下文。删除历史记录成功时也会清理该对话尚未处理的截图文件，但不等于删除 CLI 自己维护的原生历史。

## 常见问题

| 现象 | 检查方法 |
| --- | --- |
| API 401 | 检查密钥是否有效、是否有该模型权限 |
| API 404 | 检查基础地址和模型 ID；不要重复填写接口路径 |
| API 400 | 确认模型支持图片，且所选接口格式与服务一致 |
| CLI 找不到或无法启动 | 先安装登录，检查本机路径或 PATH；Windows 使用原生 exe 或标准 npm cmd |
| CLI 没有返回可用回答 | 更新 CLI，检查其账户、模型和后端配置；不兼容版本可能不支持所需参数 |
| API 429 | 查看服务商额度或限流设置，减少提问频率 |
| 无法连接 API | 检查网络。远程接口必须是 HTTPS，本地服务可用 HTTP |
| 没有讲解记录 | 检查是否已提问、系统声音是否启用及本地语音组件是否完整；静音不会生成讲解文字，平时只缓存音频 |
| 公式看不清 | 放大课程窗口或画面，采集更清晰的一帧再问 |
| 模型说错了 | 对照来源；问“你依据哪张图？缺少了什么前提？” |

本版不内置代理设置。API 模型目录、读图、问答和转写共用 Electron 系统会话，使用系统代理配置；也可使用兼容 HTTPS 网关或本机服务。不要把密钥放进 URL。

重新选择课程窗口默认继续当前课程，不会自动创建新对话。更换课程时，请先点击 **开始新的学习**，或在窗口选择器中选择相应的新课程选项，让新旧课程使用独立上下文。

回答随服务返回的文本分块显示；取消或断流保留已收到的文字并标注中断。若兼容服务忽略流式请求、返回整段 JSON，则按其实际返回显示完整答案，不播放模拟打字动画。

支持快速模式的模型旁会显示闪电按钮。点击高亮开启，再点关闭；默认关闭，仅用于答疑。快速模式可能增加费用或额度消耗，悬停可查看提示。更换模型或连接后恢复关闭，后台笔记与本地转写不跟随加速。
